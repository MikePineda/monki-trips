# Lessons

Dated one-liners: what did not work as written, where (laptop/cloud/CI), what
changed. The master distils the general ones into the project playbook.

- 2026-11-07 (laptop): the plan pins Node 24.22.2 but nvm on the laptop has 24.20.0; `.nvmrc` and the Docker base image use 24.20.0 (`node:24.20.0-slim`); bump both together.
- 2026-11-07 (laptop): `npm view typescript` reports 7.0.2, but Angular 22.2 compiler-cli and build require `>=6.0 <6.1`; every workspace pins `~6.0.3`.
- 2026-11-07 (laptop): `@types/node` latest is 26.x; pinned `~24.19.2` to match the Node 24 runtime, and Dependabot ignores its majors.
- 2026-11-07 (laptop): host port 5432 was taken by another project's Postgres; `compose.dev.yaml` takes the host port from `DB_PORT` (default 5432) and the suite ran with `DB_PORT=5434` (process env wins over `.env.test`).
- 2026-11-07 (laptop): `Env.rules().validate()` reads `process.env` before the given values, so a test cannot prove a missing variable fails; `start/env_schema.ts` exports `validateEnv`, which applies the same rules to only the given values.
- 2026-11-07 (laptop): validator-lite treats an empty string as "not set" for optional rules, so empty `S3_*` values already pass; requiring them with `DRIVE_DISK=s3` needed an explicit cross-variable check.
- 2026-11-07 (laptop): Angular 22 lazy chunks use mixed-case hashes (`chunk-D436evU6.js`); the reference uppercase-only regex gave them a 1 h cache instead of `immutable`. The regex now accepts mixed case but needs an uppercase letter or a digit.
- 2026-11-07 (laptop): Lucid 22 schema generation (on by default in development) wrote `database/schema.ts` with only an unused import when there are no tables, failing `tsc`; disabled until the first model.
- 2026-11-07 (laptop): `node ace codegen` boots the env, so it fails without `apps/api/.env` (`APP_KEY`); a fresh clone must create it first (CI and the cloud hook too).
- 2026-11-07 (laptop): Playwright 1.65 needs chromium headless shell v1254, not installed by `npm install`; ran `npx playwright install chromium`.
- 2026-11-07 (laptop): `@angular/pwa` is an `ng add` schematic, not a runtime dependency; the manifest, `ngsw-config.json` and `provideServiceWorker` were written by hand with `@angular/service-worker`.
- 2026-11-07 (laptop): the session guard of `@adonisjs/auth` needs a user model, which does not exist before WP 0.5; only `@adonisjs/session` with the cookie store is installed now.
- 2026-11-07 (laptop): Prettier with the AdonisJS config rewrites `[data-theme="dark"]` to single quotes in CSS; a spec that matched the double-quoted selector broke after `--write`. Run the specs after formatting.
- 2026-11-07 · test guard · expected to need dns.lookup to stop fetch → on Node 24.20 patching net.Socket.prototype.connect alone already blocks undici fetch (TLS sockets inherit it; dns.lookup is also reached) → the guard patches connect, tls.connect and both dns lookups; fetch rejects with TypeError "fetch failed" whose `cause` is `no-network: blocked <host>`.
- 2026-11-07 · test guard · https' default agent passes null-prototype options to tls.connect, so String(options) threw "Cannot convert object to primitive value" → never coerce connect arguments to strings; spec covers https.get.
- 2026-11-07 · cloud hook · plan's stamp write `sha256sum … > node_modules/.cloud-setup.sha256` fails when nothing is installed (no node_modules) → `mkdir -p node_modules` first.
- 2026-11-07 · cloud hook · CLAUDE_ENV_FILE is run as shell code before every Bash command, so `echo "export PATH=$PATH"` breaks on spaces and grows PATH on each resume → write `printf 'export %s=%q'` and drop the old /opt/node24/bin entry first.
- 2026-11-07 · cloud hook · `su postgres -c "psql -f $PWD/…"` depends on the checkout being readable by postgres → feed fallback.sql on stdin.
- 2026-11-07 · cloud hook · a WARN for a missing PRIVACY_PATTERNS would fail cloud-parity (CI has no such variable) → presence is reported as a plain status line, never a WARN.
- 2026-11-07 · privacy · the owner's private patterns also match the public GitHub handle, and the generic e-mail check flags no-reply addresses → the handle appears only inside the canonical repo URL; scripts derive it with `cut -d/ -f2`; REST paths use $REPO from the origin remote; regexes for no-reply addresses escape their dots.
- 2026-11-07 · privacy · `printf … | grep -q` under `set -o pipefail` can report a match as failure (SIGPIPE on the writer) → check-commits feeds grep with here-strings.
- 2026-11-07 · settings · `Bash(git push --force:*)` is a prefix rule (`:*` equals ` *`): `git push origin x --force` and `git push origin +x` slip through → extra mid-command deny rules; the ruleset (non_fast_forward) stays the real barrier.
- 2026-11-07 · lockfile · the guard on a sibling repo's lockfile found an install script (@parcel/watcher) with no allowScripts entry, silently skipped by npm → the guard treats a missing decision as an error; `true` or `false` both count.
- 2026-11-07 · image · node:24-slim alone is 236 MB uncompressed (arm64) and the runtime image is 260 MB (`docker image inspect .Size`, overlay store) → the image-arm64 budget is IMAGE_MAX_MB=450 uncompressed in ci.yml.
- 2026-11-07 · node · .nvmrc is 24.20.0 (the plan said 24.22.2) → the cloud setup script's NODE_VERSION and the pre-pulled node image follow .nvmrc; test-offline reads it at runtime.
